# ServicioProductos WCF

Servicio WCF para gestión de productos (ListarProductos, ObtenerProducto).

## Endpoints
- http://localhost:8083/ServicioProductos/ProductoService.svc
- WSDL: .../ProductoService.svc?wsdl

## Operaciones
- ListarProductos() → List<Producto>
- ObtenerProducto(int id) → Producto

## Datos en memoria (DataProducto)
5 productos hardcoded: Laptop, Mouse, Teclado, Monitor, Auriculares.
